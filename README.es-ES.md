

# Demostrador de estilos de Quasar (quasar-styles)

Un proyecto de Quasar

## Instalar las dependencias
```bash
yarn
# or
npm install
```

### Iniciar la aplicación en modo de desarrollo (recarga de código en caliente, informe de errores, etc.)
```bash
quasar dev
```


### Ejecutar lint en los archivos
```bash
yarn lint
# or
npm run lint
```


### Formatear los archivos
```bash
yarn format
# or
npm run format
```


### Compilar la aplicación para producción
```bash
quasar build
```

### Personalizar la configuración
Consulta [Configurar quasar.config.js](https://v2.quasar.dev/quasar-cli-vite/quasar-config-js).
